# 有障碍物房间的热力图采集与训练计划

> 制定时间：2026-10-16 ｜ 状态：**仅计划，未改任何代码**
> 前提：房间内障碍物（家具等）的位置、形状**不输入系统**；系统只知道房间是矩形。
> 当前系统已就位的基础：房型导入会标注「空置（空无一物）」、空房基准模型可复用。

---

## 1. 核心思路（一句话）

静态障碍物在 CSI/RSSI 上的表现是**稳定的空间偏移（阴影衰落）**，不是随机噪声——
所以策略不是"识别障碍物"，而是让模型把这种稳定偏移当作空间场的一部分吸收掉，
并用**空房基准 + 多链路分集 + 严格的跨场景评估**保证精度不掉链子。

## 3. 采集策略建议

1. **保留空房基准轮**：每种房型先采一轮空房（当前系统已支持并标注），作为背景扣除参照和模型先验。
2. **障碍物摆放协议**：障碍物不进系统，但**摆放要有记录纪律**——每种摆放配置记为一个"采集轮次"
   （系统已有轮次 r1/r2… 概念可复用），换个摆法开新轮次；AP 和采集板位置全程固定。
3. **测点不变、轮次加倍**：测点网格沿用房型自动生成的点位；同一网格在多种障碍物配置下各采一轮，
   用"配置多样性"替代"障碍物标注"。
4. **遮挡区附近加验证点**：验证点优先放在典型遮挡位（大家具背后、LOS 被挡的链路末端），
   专门考校模型在阴影区的表现。
5. **双板继续用**：两块板本身就是空间分集的一条链路（见下），障碍物场景下价值更大。

## 4. 特征工程建议

1. **增益不变归一化**（抄 espectre）：AGC 保持开启，特征用变异系数 std/mean，设备换增益不失效。
2. **子载波多样性**（抄 espectre / andyzaur）：取 ~12 个分散子载波（运动/遮挡扰动在约 10 个子载波上相干、
   噪声逐频点独立），或直接上 64 子载波幅度统计 + RSSI 组合。
3. **背景扣除**（RTI 经典做法）：每轮特征减去空房基准轮的同点位统计量，得到"障碍物增量"，
   增量比绝对值更稳。
4. **多链路分集**（andyzaur 的第一手段）：有条件时加到 2~3 个接收机；遮挡只挡部分链路，
   多数表决/加权即可拉回精度。这是调研中证据最强的一条。

## 5. 模型与评估建议

1. **模型形态：空房模型 + 残差学习**。现有"路径损耗 + GP 残差"架构不用推翻：
   空房模型当先验，障碍物配置的数据学二阶残差。GP 的方差输出天然可当"疑似遮挡区"置信度标在热力图上。
2. **评估协议必须防泄漏**（andyzaur 的硬教训）：**禁止随机切分帧**——随机切帧会把虚高误差
   当成绩（他们实测 28cm 虚高 vs 真实 60cm）。按**采集轮次/天**做 leave-one-round-out / leave-one-day-out。
3. **跨配置泛化是主考核指标**：训练用 N-1 种障碍物配置，留 1 种没见过的配置做测试——
   这才是"障碍物不建模"的真实能力，别报同配置内的精度。
4. **接受时漂、留校准预案**：跨天误差客观存在（他们实测 80cm，同日短校准回到 43cm），
   部署侧预留"3~5 个同日快速校准点"的流程。
5. **别指望神经网络自动泛化**（DensePose from WiFi 的反面教材）：端到端深度模型跨环境退化明显；
   覆盖式采集 + 简单鲁棒模型 > 复杂模型 + 单一环境数据。

## 6. 分阶段落地路径

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| 0（已完成） | 房型导入 + 空房标注 + 空房基准采集 | 当前系统即是 |
| 1 | 同一房型下采 3~4 种障碍物配置（各一轮） | 数据按轮次归档，有空房基准轮 |
| 2 | 特征升级：背景扣除 + 子载波统计（改 04） | 特征表含空房增量列 |
| 3 | 模型升级：空房先验 + 残差学习 + 置信度图层（改 05） | 热力图附带不确定度 |
| 4 | 评估：leave-one-config-out 协议 | 报告跨配置精度（而非同配置） |
| 5（可选） | 加第 2~3 接收机做空间分集 | 遮挡区精度显著提升 |
