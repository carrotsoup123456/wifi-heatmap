使用说明

这是什么

对着房间平面图逐点采集 Wi-Fi 信号，一键训练模型并画出信号热力图。分两种模式：

  • 演示模式：不需要任何硬件，用模拟数据跑通全流程（给评委演示用这个）。
  • 真实模式：接 ESP32 开发板采集真实信号。右上角可切换模式。

演示模式：三步出图

  1. ①房型：选形状（方形/长方形/L 型/U 型）、确认尺寸和路由器位置 → 点「生成测点并预览」→「应用房型」。只改路由器位置时会问你要不要保留已采数据。
  2. ③采集：点「开始采集」，系统自动逐点采集（演示模式每点约 1 秒）。
  3. ④整理出图：点「训练并出图」，得到热力图 + 模型评估报告；「一键下载」打包全部结果。

真实模式：完整流程

  1. ⓪烧录（每块板首次一次）：USB 数据线连板子 → 展开第 0 步 →「⚡ 一键烧录」→ 填 2.4GHz Wi-Fi 名和密码 →「📶 一键配网」。需要 Chrome / Edge。
  2. ①房型：同演示模式，按真实房间设置。
  3. ②设备：点「发现设备」，搜到刚配网的板子（板子和电脑要连同一个 2.4GHz Wi-Fi）。
  4. ③采集：拿着设备站到提示的点位，逐点采集；空房采集时人离开房间。
  5. ④整理出图：同演示模式。

常见问题

  • 检测不到串口：换 USB 数据线（充电线不行）；macOS 一般免驱，识别不到时换个 USB 口。
  • 烧录连不上板子：按住 BOOT → 点按 RESET → 松开 BOOT，再重试。
  • 发现不了设备：确认板子和电脑在同一个 2.4GHz Wi-Fi；路由器关掉「AP 隔离/客户端隔离」；板子用充电宝供电最稳。
  • 配网失败：确认 Wi-Fi 名/密码正确；必须是 2.4GHz（很多“5G”后缀的是 5GHz，连不上）。
  • 采集中断：已采的点会保留，重新点开始即可续采。
  • 开始新一轮：上一轮的原始文件会自动归档到 data/_archive/（不删除，可回溯），本轮从空目录重新采。
  • 采到一半怕丢/想看效果：数据每采完一个点就自动保存到本机；「下载当前数据」任何时刻都能打包已采数据（含进度清单）；采够 4 个点就能先「整理数据 → 生成热力图」看初步效果，采完再出最终版。
  • 换房型：点位变了会清空已采数据（有确认提示）；只改路由器位置可以选择保留。

数据在哪

全部保存在本机项目目录：采集数据在 data/points/（实时写入），结果图和报告在 outputs/；「下载当前数据」随时可打包，演示模式的数据是模拟生成的，仅用于演示。
